# Allan Fontes | BPM e Mapeamento de Processos

Site profissional sobre BPM, BPMN 2.0, mapeamento de processos, palestras e cursos.

## Sobre o projeto

Este site foi criado para reunir conteúdos, artigos e materiais institucionais sobre Gestão de Processos, com foco em aplicação prática no setor público e privado.

## Conteúdo do site

- Página inicial com posicionamento profissional
- Artigos sobre BPM e BPMN 2.0
- Apresentação de palestras e cursos
- Contato profissional
- Imagens e banners institucionais

## Estrutura

- `index.html` — página inicial
- `_config.yml` — configuração do site
- `_posts/` — artigos do blog
- `images/` — imagens e banners
